# PassForge

Gerador de senhas com visual hacker clássico em verde e preto.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — estilização
- `main.js` — geração, força e cópia das senhas

## Como usar

Abra o arquivo `index.html` no navegador ou publique o repositório com GitHub Pages.

## GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `main.js` e `README.md`.
3. Acesse **Settings > Pages**.
4. Em **Source**, selecione `Deploy from a branch`.
5. Escolha a branch `main` e a pasta `/root`.
6. Salve e aguarde o endereço público.
